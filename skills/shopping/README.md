# Shopping

Finding and comparing real products with live prices.

- [amazon-search](amazon-search/) - Real Amazon listings with live search-page prices from any regional storefront (amazon.ca, amazon.com, amazon.co.uk, amazon.de, and more) through a local Camoufox browser. Search only: no login, no cart, no checkout. Built for a Muse VM, so its setup notes are Muse-specific.
