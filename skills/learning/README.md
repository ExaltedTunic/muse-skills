# Learning

Skills for building and teaching with structured learning material: courses treated as engineered artifacts, where content is data, claims are gated, and progress is measured in units the learner actually consumes.

- [language-curriculum-engineering](language-curriculum-engineering/) - Build and maintain a CEFR-banded language course as data with validation gates: input-mass budgeting in reading words, listening minutes and lemmas, declared-vs-delivered lexis measurement, gloss coverage, assessment integrity with provable model answers and cross-mode pass parity, manifest-accounted generated audio, strict-vs-lenient metric honesty, and native-speaker recording packs.
