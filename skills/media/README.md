# Media

Skills for producing generated media as an engineered artifact: catalogues with manifests, provenance, and validation, rather than piles of files.

- [generated-audio-pipeline](generated-audio-pipeline/) - Run a pre-generated audio catalogue as a pipeline: manifest as source of truth with per-asset engine and voice provenance, codec choice as an explicit compatibility decision with a documented degradation chain, churn-controlled regeneration, orphan lifecycle management in shared object storage, a written two-engine cost policy, and byte-level verification that catches silent empty renders.
